# Laboratorio 11 — Ejercicio 1

Next.js App Router + TypeScript + Tailwind CSS 4 + CSS Modules.

## Ejecutar

```bash
npm install
npm run dev
```

Abrir **http://localhost:3000/styling**. La ruta raíz también redirige allí.

## Capturas solicitadas

Capturar `/styling`, los efectos hover, la validación de email y el botón de carga.

## Descripción del resultado

La combinación de CSS Modules y Tailwind CSS permite construir componentes reutilizables, separando las animaciones y estilos especiales en módulos CSS y la estructura adaptable, el espaciado y los colores en clases utilitarias de Tailwind. Esto mejora la organización y facilita el mantenimiento del proyecto.
